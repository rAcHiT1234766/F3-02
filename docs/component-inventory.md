## Acceptance reference

- **Button:** Primary, secondary, danger; three sizes; disabled/loading. Acceptance: Correct native behavior; no accidental form submission.
- **IconButton:** Icon action with accessible name; sizes. Acceptance: Screen reader announces action without seeing icon.
- **Link:** Native anchor with documented external-link use. Acceptance: Keyboard activation and expected href behavior.
- **Text:** Body/caption styles; semantic element choice kept small. Acceptance: Styling does not force an incorrect HTML role.
- **Heading:** Levels 1–6 independently from visual size. Acceptance: Correct heading element in DOM.
- **Badge:** Status/category label; semantic variants. Acceptance: Meaning remains understandable without color.
- **Avatar:** Image and initials fallback. Acceptance: Broken image fallback; useful or decorative alt policy.
- **Separator:** Horizontal/vertical; decorative option. Acceptance: Semantic separator only when meaningful.
- **Spinner:** Small loading indicator with optional status label. Acceptance: Decorative spinner does not duplicate announcements.
- **Skeleton:** Placeholder blocks and reduced-motion treatment. Acceptance: Placeholder shapes hidden from assistive technology.
- **Progress:** Determinate and indeterminate progress. Acceptance: Value/label semantics match rendered state.
- **VisuallyHidden:** Text available to assistive technology. Acceptance: Hidden content stays available to accessibility tree.
- **Box:** Simple block wrapper with documented styling escape hatch. Acceptance: Supports native attributes without layout surprises.
- **Stack:** Horizontal/vertical flow with token gaps. Acceptance: Long content wraps or overflows as documented.
- **Grid:** Small responsive column API. Acceptance: Mobile layout does not overflow.
- **Container:** Centered content width and responsive gutters. Acceptance: Narrow viewport remains usable.
- **Card:** Surface with optional header/content/footer composition. Acceptance: Does not create invalid nested interactive elements.
- **Input:** Native text/email/password/number input passthrough. Acceptance: Labels, refs, value updates, disabled/read-only states.
- **Textarea:** Multiline input, rows, resize policy. Acceptance: Controlled and uncontrolled editing work.
- **Checkbox:** Checked, unchecked, indeterminate, disabled. Acceptance: Label activation and mixed-state announcement.
- **RadioGroup:** Single choice with group label and disabled options. Acceptance: Native arrow-key behavior and one selected item.
- **Switch:** Boolean setting with stable label. Acceptance: State changes by keyboard and is announced.
- **Select:** Styled native single-select with options and placeholder. Acceptance: Native keyboard selection; label and value work.
- **FormField:** Label/help/error association for one control. Acceptance: Correct IDs and described-by wiring.
- **Fieldset:** Related controls with legend/help/error. Acceptance: Group has an understandable accessible name.
- **SearchInput:** Search field with optional clear action. Acceptance: Clearing updates state; clear action has a name.
- **Slider:** Native single-thumb range with min/max/step. Acceptance: Arrow keys and accessible value/units work.
- **Tabs:** One active panel with labeled tab list. Acceptance: Arrow navigation, activation, and panel association.
- **Accordion:** Expand/collapse sections; single or multiple mode. Acceptance: Heading buttons expose expanded state.
- **Breadcrumbs:** Ordered navigation trail and current page. Acceptance: Named navigation; current page is identified.
- **Pagination:** Previous/next and page selection. Acceptance: Boundaries disabled; current page indicated.
- **DropdownMenu:** Action menu with disabled items and separators. Acceptance: Arrow navigation, Escape, and focus return.
- **Modal:** Dialog with title, content, actions, and close behavior. Acceptance: Focus contained and restored; background unavailable.
- **AlertDialog:** Explicit confirmation of a consequential action. Acceptance: Cancel is safe; outside click cannot confirm.
- **Drawer:** Side-panel modal using shared dialog behavior. Acceptance: Same focus rules as Modal; small screens usable.
- **Tooltip:** Short supplemental text on hover/focus. Acceptance: Keyboard access and Escape; no interactive content.
- **Popover:** Anchored non-modal supplemental content. Acceptance: Correct focus policy and dismissal.
- **Toast:** Queued feedback, dismissal, optional action. Acceptance: Announcements and timers do not obstruct use.
- **Alert:** Persistent inline status/warning/error message. Acceptance: Live announcement only when context warrants it.
- **Table:** Semantic table parts with caption, headers, empty state. Acceptance: Header associations and horizontal overflow work.
- **DataGrid:** Table-based sorting, paging, selection, and search. Acceptance: Stable row IDs; sorting/filtering/paging cooperate.
- **Calendar:** Single-date selection and month navigation. Acceptance: Keyboard navigation and disabled dates work.
- **DatePicker:** Date field plus calendar dialog, clear, min/max. Acceptance: Typed and selected dates agree; no timezone shift.
- **Combobox:** Editable single-select with local filtering. Acceptance: Keyboard selection, Escape, no-results behavior.
