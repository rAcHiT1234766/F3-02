# Individual reflection prompts

Owner input required. This document is not a completed personal reflection.

- What work did you personally own, implement and review?
- Which component API or behavior decision did you make, and why?
- Which code or behavior came from third-party libraries?
- Describe a real defect you investigated: evidence, hypothesis, fix and retest.
- What did keyboard/screen-reader review change in your design?
- Where did AI assist, and how did you verify its output?
- What remains incomplete, and what would you prioritize with another week?

Use first-person claims only for work and learning you can substantiate. Code
written by the assistant and tests run by tools should be attributed accurately.
