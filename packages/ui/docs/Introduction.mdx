# Foundation UI

An accessible, token-driven React component library: 44 components, light and dark
themes generated from Figma, and one compiled stylesheet with no setup for consumers.

## Get started

Import components and the stylesheet once, then set a theme on any container.

```tsx
import { Button, FormField, Input } from '@rachitp72/foundation-ui';
import '@rachitp72/foundation-ui/styles.css';

export function Profile() {
  return (
    <form data-ui-theme="light">
      <FormField id="name" label="Full name" required>
        {(props) => <Input {...props} name="name" />}
      </FormField>
      <Button type="submit">Save</Button>
    </form>
  );
}
```

React 19 is the only peer dependency. Consumers don't need Tailwind, Style Dictionary
or any build configuration.

## Principles

- **Accessible by default.** Labels, error messages, focus management and keyboard
  support are built in, targeting WCAG 2.2 AA. See [Accessibility](?path=/docs/guides-accessibility--docs).
- **Native first.** Components render real `button`, `input`, `select` and `table`
  elements and pass native props and refs through.
- **Token-driven.** Every colour, space, radius and font size is a design token
  defined in Figma. See [Design tokens](?path=/docs/guides-design-tokens--docs).
- **Typed and composable.** Strict TypeScript APIs, controlled or uncontrolled inputs,
  and small pieces that compose (FormField + Input, DataGrid built from Table, Checkbox
  and Pagination).
- **No side effects on the host.** Styles are prefixed and ship without a global reset,
  and each component is its own module, so unused components are not bundled.

## Theming

Set `data-ui-theme="light"` or `"dark"` on any element; themes can be nested, and
dialogs, menus and tooltips follow the theme of the element that opened them. Use the
**paintbrush** button in the toolbar to switch every story between themes.
