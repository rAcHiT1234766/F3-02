# Colors

Colours come in two tiers. **Palette** tokens are raw brand values. **Semantic** tokens
describe a job (`action`, `text`, `danger`) and have a light and a dark value; components
only ever use semantic tokens, which is what makes theming work. Every value below is read
live from the generated CSS, so it always matches the Figma export.

In CSS each token is a custom property: `color.actionHover` becomes
`var(--fui-color-action-hover)`.

## Contrast

WCAG 2.2 AA asks for 4.5:1 for normal text and 3:1 for borders and focus indicators.
These ratios are computed live from the tokens; the same pairs are checked on every
build by `npm run test:contrast`, so a Figma change that breaks contrast fails the build.
