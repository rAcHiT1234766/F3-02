# Spacing and radius

## Spacing

An eight-step scale in `rem`, so spacing grows with the user's browser font size.
Use it for padding, gaps and margins: `var(--fui-space-4)`.

<SpacingScale steps={[1, 2, 3, 4, 5, 6, 7, 8]} />

| Typical use                         | Token               |
| ----------------------------------- | ------------------- |
| Gap between an icon and its label   | `space.2`           |
| Control padding, gaps in a form row | `space.3`–`space.4` |
| Card padding, gaps between fields   | `space.5`           |
| Gaps between page sections          | `space.6`–`space.8` |

## Corner radius

<RadiusScale sizes={['sm', 'md', 'lg']} />

`radius.sm` rounds controls and small surfaces: buttons, inputs, badges, menu items,
toasts and the table frame. `radius.md` rounds cards and tooltips. `radius.lg` is
defined in Figma but not yet used by a component; it is reserved for large surfaces.
